# Persona 5 Royal Cheatsheet

![P5R Cheatsheet](https://i.imgur.com/fake-image-url.png)

A comprehensive companion app for Persona 5 Royal players, helping you optimize your gameplay with quick access to confidant responses, shadow negotiations, and crossword answers.

## Features

### Confidant Guide
- Complete database of all 19 confidants in the game
- Every dialog option with point values clearly marked (+3, +2)
- Color-coded responses for easy identification of the best choices
- Quick filtering by confidant name or response text

### Shadow Negotiations
- All shadow negotiation questions and answers in the game
- Color-coded responses showing effectiveness with different personality types:
  - Gloomy
  - Irritable
  - Timid
  - Upbeat
- Filter negotiations by personality type to quickly find the best responses

### Crossword Puzzles
- Complete list of all crossword answers in the game
- Search by clue or answer to find what you need

### Other Features
- Dark mode interface that matches the game's aesthetic
- Responsive design that works on both mobile and desktop
- Fast, client-side searching across all data
- Simple, intuitive navigation between different sections

## Why Use This App?

### Maximize Your Gameplay Time
- No more wasted game time selecting suboptimal responses
- Quickly rank up confidants by always choosing the best dialog options
- Successfully negotiate with shadows on the first try
- Solve crossword puzzles instantly to gain knowledge points

### Better Than Wikis and Guides
- Focused interface designed specifically for finding information quickly
- No ads or distractions
- Works offline after initial load
- More comprehensive and better organized than most online guides

### Perfect Companion for:
- First-time players who want to optimize their playthrough
- Experienced players going for 100% completion
- Anyone trying to max all confidant relationships in a single playthrough

## Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/p5r-cheatsheet.git

# Navigate to the project directory
cd p5r-cheatsheet

# Install dependencies
npm install

# Start the development server
npm start
```
